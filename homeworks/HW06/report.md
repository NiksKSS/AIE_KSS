## 1. Dataset


- Какой датасет выбран: `S06-hw-dataset-02.csv`
- Размер: (18000, 39)
- Целевая переменная: `target`:
  - Класс 0: 13273 (примерно 74%)
  - Класс 1: 4727 (примерно 26%)
- Признаки: почти все признаки — числовые (f01–f37 и ещё один числовой). `id` — просто номер строки, как признак я его не использовала.


## 2. Protocol


- Разбиение: я поделила данные на train/test = 75%/25%, поставила `random_state=42` и `stratify=y`, чтобы результат был повторяемый и чтобы доли классов в train/test были похожи.
- Подбор: параметры подбирала только на train через кросс-валидацию (5 фолдов). Оптимизировала ROC-AUC.
- Метрики:
  - Accuracy — просто процент правильных ответов.
  - F1 — полезна, когда классы не совсем равные по количеству.
  - ROC-AUC — показывает, насколько хорошо модель отделяет класс 1 от класса 0 по вероятностям (это удобно для бинарной задачи).


## 3. Models


Я сравнила такие модели:

- DummyClassifier — самый простой baseline (всегда выбирает самый частый класс).
- LogisticRegression — baseline с нормализацией признаков через StandardScaler.
- DecisionTreeClassifier — дерево решений; я ограничивала сложность через `max_depth` и `min_samples_leaf`.
  - Лучшие параметры: `max_depth=10`, `min_samples_leaf=20`.
  - Лучший CV ROC-AUC: 0.8372.
- RandomForestClassifier — много деревьев (ансамбль); подбирала `max_depth`, `min_samples_leaf`, `max_features`.
  - Лучшие параметры: `max_depth=None`, `max_features="sqrt"`, `min_samples_leaf=5`.
  - Лучший CV ROC-AUC: 0.9236.
- GradientBoostingClassifier — boosting; подбирала `n_estimators`, `learning_rate`, `max_depth`.
  - Лучшие параметры: `learning_rate=0.1`, `max_depth=3`, `n_estimators=400`.
  - Лучший CV ROC-AUC: 0.9185.


## 4. Results


Метрики на test (accuracy / F1 / ROC-AUC):

- DummyClassifier: 0.7375 / 0.0000 / —
- LogisticRegression: 0.8119 / 0.5607 / 0.7977
- DecisionTree: 0.8334 / 0.6515 / 0.8373
- GradientBoosting: 0.8953 / 0.7797 / 0.9179
- RandomForest: 0.8858 / 0.7452 / 0.9203

Победитель: **RandomForest (rf)**, потому что у него самый большой ROC-AUC на test (0.9203), а по заданию мы выбираем лучшую модель по согласованной метрике.


## 5. Analysis


- Устойчивость: отдельные 5 прогонов с разными `random_state` я не делала, поэтому устойчивость не проверяла.
- Ошибки (confusion matrix для rf): TN=2588, FP=67, FN=344, TP=601.
  - FP мало (67) — модель редко ошибочно говорит 1, когда на самом деле 0.
  - FN заметно (344) — часть объектов класса 1 модель пропускает.
- Интерпретация (permutation importance, top-15): самый важный признак — `f16`, дальше по важности идут `f01`, `f19`, `f12`, `f23`, `f07`, `f30`, `f08`, `f18`, `f02`, `f05`, `f33`, `f29`, `f13`, `f11`.
  - Вывод: `f16` сильнее всего влияет на качество, остальные признаки тоже полезны, но слабее.


## 6. Conclusion


- DummyClassifier показал, что если всегда угадывать самый частый класс, accuracy может быть нормальной, но F1 будет плохой.
- LogisticRegression лучше dummy, но хуже ансамблей.
- Дерево решений нужно ограничивать по сложности, иначе оно легко переобучается.
- Ансамбли (RandomForest и GradientBoosting) дали лучшее качество на этом датасете.
- Важно делать честный эксперимент: подбирать параметры на train через CV и только один раз смотреть на test в конце.
