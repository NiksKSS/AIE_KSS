# Исходный код

## Файлы

- `config.py` — конфигурация проекта (пути к данным, модели, переменные окружения)
- `streamlit_app.py` — основной сервис: Streamlit-интерфейс с прогнозом и картой
- `models/predictor.py` — утилита для загрузки модели и выполнения инференса

## Запуск

```bash
cd project
PYTHONPATH=. streamlit run src/streamlit_app.py
```

## Структура Streamlit-интерфейса

1. Боковая панель: выбор муниципалитета и даты
2. Основная область: прогноз погодных параметров
3. Вкладка «Карта»: визуализация на карте муниципалитетов
4. Вкладка «История»: исторические данные
