# Ноутбуки экспериментов

В этой папке находятся ноутбуки с экспериментами по обучению и оценке моделей.

## Файлы

### train_model.ipynb

Основной ноутбук обучения модели. Содержит:

1. **Загрузка и разбиение данных**
   - Данные разбиты по годам: TRAIN (2018–2023), VAL (2024), TEST (2025)

2. **Базовые модели**
   - Линейная регрессия
   - Дерево решений
   - Сравнение по метрикам MAE, RMSE, R²

3. **Улучшенная модель**
   - ExtraTreesRegressor с подбором гиперпараметров
   - RandomizedSearchCV для оптимизации

4. **Финальная модель**
   - Обучение на полном TRAIN-наборе
   - Оценка на TEST
   - Сохранение артефакта в `artifacts/model.pkl`

5. **Метрики по таргетам**
   - Таблица с MAE, RMSE, R² для каждой из 8 целевых переменных
   - Анализ сильных и слабых таргетов

## Использование

Ноутбук предназначен для просмотра в Jupyter/Google Colab. Для запуска локально:

```bash
cd project
jupyter notebook notebooks/train_model.ipynb
```

Или откройте в VS Code через расширение Jupyter.
